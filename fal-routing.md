# fal — каталог і маршрути відеовиробництва

Знімок 19 листопада 2026. [CSV для фільтрування](catalog/fal-endpoints.csv) · [JSONL з вихідними полями](catalog/fal-endpoints.jsonl) · [Охоплення](catalog/coverage.json) · [Схеми shortlist](catalog/schemas.json) · [Ціни shortlist](catalog/pricing.json).

Перевірено 1 404 унікальні активні endpoints у 28 категоріях за 15 сторінок без дублікатів до кінцевого курсора. У центрі workflow — 114 text-to-video, 186 image-to-video, 190 video-to-video, 14 audio-to-video, 6 video-to-audio, 4 video-to-text та 11 speech-to-text. Інші категорії покривають 3D, world assets, картинки, звук, utility, training і orchestration. Весь реєстр збережено на рівні endpoint, категорії, тегів і нотаток про callable. Каталог динамічний; порядок recent означає дату реєстру, не оцінку якості. Для 30 кандидатів отримано поточні схеми, для 10 — тарифи. [Повний перелік параметрів для 30 моделей](fal-parameters.md). Решта мають каталожну перевірку, параметри і тарифи слід читати перед виконанням.

## API, гроші та збереження

- У Codex використовувати підключений fal: **catalog/schema/price → вибір endpoint → після підтвердження бюджету submit → request ID → status/result → локальний ingest**. Якщо потрібен прямий SDK, окремо перевірити account-level ключ у захищеному сховищі та інжектувати `FAL_KEY` тільки у server-side runtime. Наявний OAuth не доводить наявність окремого ключа. Значення ключа не вносити в JSON, командний рядок, файли проєкту чи матеріали рев’ю. [fal model APIs](https://docs.fal.ai/model-apis)
- Доступ до asset URL має бути тільки на потрібний строк. Зберігати SHA-256 джерела, endpoint, роздільну здатність, модель, request ID і версію prompt; signed URLs, credentials та сирі приватні матеріали тримати за межами каталогу. Повторно використовувати успішні immutable results. При тимчасовій втраті відповіді отримати той самий job за request ID перед повторною оплатою.
- Приклади USD за поточним тарифом конектора: H3 Max I2V $0.0375/сек, Gemini Omni edit $0.0273/сек, Sync v3 $8/хв, Scribe v2 $0.008/хв і VEED Dubbing Pro $0.18 за вхідну секунду. Token-based або `units` потребують окремої перевірки формули. Preview, audio, роздільна здатність, округлення й повтори можуть впливати на бюджет.
- Billing check повернув `balance_exhausted` для підключеного акаунта. Файли не завантажувалися, моделі не запускалися. Після поповнення балансу спочатку один короткий кліп на функцію і контроль вартості. [fal credits](https://fal.ai/connect/credits)
